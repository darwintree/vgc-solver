# Champions 可扩展性优化

## 目标与口径

基线提交 `69203ac`，选例来自 [benchmark 选例](../champions-benchmark-selection.md)。六个日常项及三个扩展项各做三次冷进程复测，原始数据见[本轮基线](champions-scalability-baseline-2026-09-07.jsonl)。每组 metadata 后跟对应样本，`sample` 表示重复序号。

本轮目标是恢复陆鲨／铝钢桥龙全部九档 HP 按 10 秒预算结束搜索后的可用返回，并使 U1/U2/U3 至少一项三次达到原收敛标准；两个对照保持达标，最后回归全部 54 项。正常返回与收敛分别验收，实际截止开销独立报告。

保持 Node v24.20.0、@pkmn/sim 0.10.11、同步 backend、workers=0、warmup=0、每次新进程/solver/cache、原生最大 PP、`lazyCells:false`、`selectionPolicy:auto`、tolerance=0.02、搜索预算 10 秒与外部 watchdog 30 秒。性能测量串行，与功能测试错开；功能测试通过不代表性能目标达成。

## 基线与诊断

三次采样中，两对照都达标、U1/U2/U3 及两个正常返回扩展项都未达标、两个陆鲨／铝钢桥龙实例都触发 watchdog。U2 的结束区间宽度为 0.4243、0.2521、0.2865，说明单次区间不能当作稳定性能结论。C1/C2 的 search 中位数分别为 4.646/0.928 秒。

诊断使用临时 `_expandCell` 阶段包装及 Node CPU profiler。额外将单格重放上限设为 2,000 的探针只用于定位，不能作为满预算 benchmark：W1 在根节点 Scale Shot / Flash Cannon 一格达到该上限；U1 第一格 Moonblast / Flash Cannon 也超过该数。U1 完整预算 profile 显示 deepClone、GC、原生事件分发、身份守卫、反序列化与序列化均有显著成本，矩阵求解不是主要采样热点。

独立枚举 W1 根节点 Earthquake 对对手四个合法招式的完整分布，每格 24 次重放，均聚合为概率 1、终局效用 +1。这为按实际矩阵证书提前结束根展开提供了直接依据，不需要读取 case 名称。

原来 16 个达标项全部保持达标。八个新增达标项分别是 U2、陆鲨／铝钢桥龙中 P2 HP 为 25% 或 50% 的六种组合，以及 `primarina-50-vs-archaludon-50`。原 watchdog 中剩余三个 P2 满血组合均正常返回有效区间，尚未收敛；原正常返回未收敛项中有两项变为达标，因此正常返回未达标总数为 29−2+3=30。

30 个未达标项的实际 search 为 10000.407–10004.069 ms。预算恢复目标已达成，仍明确记录约 0.4–4.1 ms 的实际截止开销，未把它们算作严格 10 秒收敛。所有 ID、跳过原因与原始筛查一致；可对照的输入逐项一致，全部原生 PP 保持最大值，区间与分类检查通过。历史区间相交只是辅助检查，正确性依据仍是算法合同和测试。

## 正确性与适用范围

- 原生截止在随机分支边界停止，未完成分布整个丢弃，格子保持未知界；不将部分概率归一化，不写入完整 PP 模板。已消耗的模拟次数仍计入统计。真实原生中断、自定义 adapter 完整 solve 和真实 worker 截止转发均有测试。
- eager 证书只停止额外工作，未知格及区间仍保留；每格通过 backup 传播，三层图和独立矩阵 oracle 的随机 DAG 测试覆盖祖先更新。非根 `1e-9` 是现有调度分辨率，根仍按用户 0.02 判定收敛。exact 求解器完整矩阵与策略合同保持。
- security 只改变展开顺序，优先处理约束行最低保证或列最高保证的可展开格子，保留混合策略与联合选择回退。没有按 case、招式或宝可梦名称分支。
- 固定方法检查保留全部原生身份条件；形状缓存依赖 solve 内快照不变的既有约定。事件与 PP 转移继续接受原生分布对照验证。
- 方法依赖区间、行动矩阵与状态复用，适用于更大搜索空间；当前同步 eager 提前停止未扩展到 worker 的批次调度。完整单打、换人、双打行动生成及真正循环求解尚未验证，本轮没有新增这些能力。

最终代码通过 `npm run typecheck`、`npm run build`、相关测试与完整 `node --test --test-concurrency=4 dist/test/*.test.js`：161/161 通过。完整测试使用提权执行，避免沙箱阻止 types 测试的 spawnSync；测试与性能测量分开运行。

## 后续 benchmark

本轮两个目标均已达成：watchdog 全部恢复返回，U2 三次在原口径下收敛，两个对照保持三次达标。U1、U3、陆鲨／铝钢桥龙的 P2 满血组合和数值边界项仍是下一轮优化对象；U2、W1 与 C1/C2 保留为回归对照。后续应继续依据实际证明与转移成本诊断，不能从本轮结果推断其他长局已可求解。

## 复现

在仓库根目录，使用固定输入快照：

```bash
npm run build
for run in 1 2 3; do
  node dist/src/champions-benchmark.js garchomp-100-vs-primarina-50
  mv champions-single.jsonl "/tmp/champions-u2-$run.jsonl"
done
node dist/src/champions-benchmark.js
```

其他选例替换完整 ID。每次单例命令会覆盖 `champions-single.jsonl`，全量结果写入 `champions-results.jsonl`；保存后再执行下一次测量。样本数三次只验证本轮环境下的重复性，进一步优化仍应重新复现基线。本轮未正式采集峰值内存或完整长局性能。
