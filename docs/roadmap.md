# 阶段目标与过关标准

## 背景与定位

项目的远期愿景是在完全明牌（Open Team Sheet）设定下，实现从 63 单打／64 双打选人开始的对战博弈求解。由于直接求解选人与满血开局面临巨大的状态组合壁垒，当前阶段坚持从 `1v1` 出发，在**纯本地 TypeScript 技术栈**下按在场人数和离比赛结束的剩余回合数一步步向外推进。

为支持按阶段自动迭代，以下每个阶段目标（Goal）**只规定测哪批局面与算对多少局过关，不预设具体实现路径**。优化原则与方法论见[架构与边界](architecture.md#项目方向与优化原则)，计时与运行口径见 [Benchmark 指南](benchmarking.md)。

## 通用底线（所有阶段必须同时满足）

1. **零报错与零卡死**：测试集内全部对局正常返回，`0 error / 0 watchdog`；不修改原始测试配置，不通过缩减满 PP 冒充性能提升。
2. **规则与官方模拟器一致**：每回合生成的合法行动与 `@pkmn/sim@0.11.0`（及 `@pkmn/mods@0.11.0` 中的官方 `champions` 规则）一致；覆盖该阶段核心机制的单步随机结果概率分布偏差满足 `TVD < 1e-8`。
3. **上下界区间真实可靠**：在小规模可穷举算出准确值的测试局上，任意预算返回的 `[lowerBound, upperBound]` 100% 包住真实极小极大值；只有区间宽度达到误差要求（`upperBound - lowerBound <= tolerance`）时才标记 `converged: true`。
4. **旧测试零退步**：每推进一个阶段，此前阶段已经过关的测试集不能退步。

## Goal 1：把单打 `1v1` 的全部 810 个测试局（含 Mega）基本算通

- **测什么**：[`fixtures/champions/`](../fixtures/champions) 中两批单打前十热门精灵的两两配对（`2026-09` 共 405 局 + `2026-11` 共 405 局，原生满 PP，包含 Mega 进化、自我再生、哈欠、树果等配置）。
- **过关标准**：
  1. 810 局全部正常跑完，`0 error / 0 watchdog`，上下界区间准确；
  2. 原已通过的 [`src/cases.ts`](../src/cases.ts) 全部 9 个基础局，以及两个快照的 `historical-54`（各 54 局）保持 **100%（`54 / 54`）** 在 `10s / 误差 <= 0.02` 内算完；
  3. 两批各 405 局全集，在独立冷进程、`workers = 0`、每局限时 `10s`、误差 `<= 0.02` 下，**每批都至少算完 90%（`>= 365 / 405` 局）**。

---

## Goal 2：把“带换人的单打残局”（双方各剩 `<= 3` 只，倒数 2～3 回合）算通

- **测什么**：从 `1v1` 扩到可换人的单打盘面（主动换人、急速折返等打完换人、倒下补位、踩钉子与登场特性），用 [`data/champions-replays/singles/`](../data/champions-replays/singles) 中 **21 场正常打完的高分单打实战录像**测试。
- **过关标准**：
  1. **规则对齐**：逐回合核对这 21 场录像，实战中玩家选择的招式与换人都在合法选项内；换人、折返暂停、死后补位等回合算出的随机结果概率与 `@pkmn/sim` 一致（`TVD < 1e-8`）；
  2. **上下界没算错**：在小规模可穷举算准的单打 `2v1 / 2v2 / 3v2` 换人局上，上下界 100% 包住真实准确值；
  3. **实战残局达标**：从这 21 场录像截出截至当回合双方参战精灵均已亮相的 `<= 3v3` 残局，在独立冷进程、限时 `10s`、误差 `<= 0.02` 下：
     - **倒数第 2 回合**的盘面，至少算完 **80%**；
     - **倒数第 3 回合**的盘面，至少算完 **60%**；
     - Goal 1 已过关的测试不退步。

---

## Goal 3：把“双打浅层残局”（双方各剩 `<= 3` 只，倒数第 2 回合）算通比例提上去

- **测什么**：双打残局（场上两只同时出招、选目标、范围伤害分摊、看我嘛／帮助、中途换人、死一只或同时死两只补位），用 [`data/champions-replays/doubles/`](../data/champions-replays/doubles) 中 **26 场正常打完的高分双打实战录像**测试。
- **过关标准**：
  1. **规则对齐**：逐回合核对这 26 场双打录像，玩家每步操作都在合法选项内；同时死两只补位、中途换人等回合的随机结果概率与 `@pkmn/sim` 一致（`TVD < 1e-8`）；
  2. **上下界没算错**：在小规模可穷举算准的双打 `2v1 / 2v2 / 3v2` 测试局上，上下界 100% 包住真实准确值；
  3. **实战残局达标**：双打录像截出的截至当回合双方参战精灵均已亮相的 `<= 3v3` **倒数第 2 回合**残局（共 20 局），在独立冷进程、限时 `30s`、误差 `<= 0.04` 下（当前基线为 `8 / 20 = 40%`）：
     - 至少算完 **65%（`>= 13 / 20` 局）**，且此前已经能算完的 8 局一局都不能退步；
     - Goal 1、Goal 2 已过关的测试不退步。

---

## Goal 4：放开到满编人数（单打 `3v3` / 双打 `4v4`），推进到倒数第 3～5 回合

- **测什么**：固定取录像库中**整场打完双方参战精灵全部亮明身份**的那 **20 场单打（`3v3`）** 和 **22 场双打（`4v4`，含双后排换人与补位）**，按已知本场参战名单还原到倒数第 3、4、5 回合作为明牌盘面。
- **过关标准**：
  1. **规则与上下界准确**：新增的 `4v3 / 4v4`（双后排换人、补位）随机分支概率与 `@pkmn/sim` 完全一致（`TVD < 1e-8`）；在小规模可穷举算准的 `4v4` 测试局上，上下界 100% 包住真实准确值；
  2. **老测试不退步**：Goal 1～3 已过关的测试不退步；
  3. **20 场单打（`3v3`）**，独立冷进程、限时 `15s`、误差 `<= 0.02` 下：
     - **倒数第 4 回合**：至少算完 **50%（`>= 10 / 20` 局）**；
     - **倒数第 5 回合**：至少算完 **35%（`>= 7 / 20` 局）**；
  4. **22 场双打（`<= 4v4`）**，独立冷进程、限时 `30s`、误差 `<= 0.04` 下：
     - **倒数第 3 回合**：至少算完 **45%（`>= 10 / 22` 局）**；
     - **倒数第 4 回合**：至少算完 **25%（`>= 6 / 22` 局）**。

---

## 后续阶段说明

走完 Goal 1～4 后，再根据这 20 场单打和 22 场双打在更早回合（直至第 1 回合开局）的真实可算完比例，决定下一阶段能否继续沿同一方式推进至满血开局与选人，或是否需要引入新的求解架构与算力方案。
