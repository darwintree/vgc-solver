# 精确价值证明：只计算证书需要的内容

## 方法：先问需要证明什么，再决定展开多少

一个子状态通常只需向父状态返回价值，不必提供完整策略或完整收益矩阵。当前 exact 搜索先生成行动组合的一步转移，将已知终局效用与待递归后继分开；只在需要该单元的精确值时递归。多个行动到达同一后继时复用 memo，同一转移内也只解一次相同后继。

一旦已计算部分足以构成精确证书，就无需为其余内容付出成本。证书失败时继续补齐，不把未知值当成已知，也不依据招式名称或低概率跳过。根节点仍必须返回完整矩阵与双方策略，不能用子状态的 value-only 合同降低根的交付要求。

## 例子一：一条必胜行足以确定价值

设 P1 有 A、B 两个行动，P2 有 C、D、E 三个行动，效用上限是 +1。先枚举 A 对 C、D、E 的全部随机结果，发现每个结果都是已知的 +1。

P1 固定选 A 就能保证 +1，而任何策略不可能超过 +1，所以这个子状态的价值已确定。B 的三个单元无论多复杂，都不影响证明，可以不递归。对称地，如果 P2 有一列所有结果都严格为 -1，该列证明 P1 的价值为 -1。

要求是“逐个 outcome 为极值”，不是“浮点期望恰好等于极值”。例如一个单元有极小概率失败，求和舍入可能看起来仍为 1；这不构成必胜证书。该边界由小于 `Number.EPSILON` 的非胜利分支回归覆盖。

## 例子二：一般纯鞍点只需要一条完整行和列

以下是方法演示，问号代表尚未计算的单元：

```text
          C      D      E
    A    0.4    0.7    0.6
    B    0.2     ?      ?
    F    0.1     ?      ?
```

完整 A 行的最小值是 0.4，说明 P1 选 A 至少保证 0.4。完整 C 列的最大值也是 0.4，说明 P2 选 C 至多允许 P1 得到 0.4。上下两份精确保证相遇，故价值为 0.4，无需解四个问号。

如果 C 列还有未求解后继，或者只知道其估计值接近 0.4，就不能用这条 exact 鞍点路径；需要继续求解。这与[有界搜索](bounded-search.md)明确返回误差区间是不同合同。若该状态被要求作为根输出，则即使已有 value-only 结果，也要补齐其完整矩阵与策略。

## 没有纯证书时：求混合策略，并复核收益保证

考虑收益矩阵 `[[1, -1], [-1, 1]]`。任一纯行最坏都是 -1，任一纯列最好都容许 +1，纯证书不能相遇。双方各以 1/2 选择两个行动则使对手的任一纯回应都产生期望 0，价值为 0。

当前矩阵方法先检测严格纯鞍点；否则将收益缩放、正移位，转为正矩阵线性规划，用 simplex 求候选策略，再从最终基重新计算原始与对偶解。最后回到原矩阵复核：P1 策略对任意列的最低收益，与 P2 策略对任意行的最高收益，应在数值容差内夹住所报价值。

这减少常规矩阵上枚举支持集的成本，也避免仅因迭代器“返回了数字”就相信它。数值失败时，最多 6×6 的矩阵允许枚举回退；更大矩阵无法验证则显式报错。simplex 没有多项式最坏时间保证，双精度证书也不是有理数符号证明。

## 推广与证据

上述方法只依赖零和收益矩阵、有限随机后继和效用界，可用于矩形行动空间；不要求 1v1 或某种 PP 数量。完整队伍会增加行动数与状态数，证书是否经常出现仍需测量。当前 exact 有限递归无法求解真正可再生循环，需要另行建立随机博弈不动点求解。
