# 有界搜索：把搜索指向尚缺的证明

## 方法：未搜索部分保留未知界，而不是猜一个值

当需求是“在给定误差内得到结果”，求出所有后继的精确值可能浪费大量工作。有界搜索为状态维护 `[L, U]`，终局为已知效用，未展开状态初始为 `[-1, 1]`。每次只展开一个前沿状态的一层转移，再向父节点回传更紧的界。

对于行动组合，分别对各后继的下界、上界按概率加权，形成下界矩阵和上界矩阵。零和矩阵价值对每个收益单元单调，因此两矩阵的价值夹住真实状态价值。当前实现还从求得的策略重新计算最低／最高收益保证，并为浮点误差留出余量，单调收窄已有区间。

输出中点的误差不超过区间宽度的一半。只有宽度满足容差才报告收敛；预算耗尽、节点限制或停滞都不是完成证明。中点不是 exact 值，访问过一个循环也不是该循环已被求解。

## 例子：0.02 宽度如何变成可检查的结果

用一个 1×1 行动矩阵隔离概率传播过程，忽略展示中的微小浮点保护余量。该行动有概率 0.75 直接胜利（+1），概率 0.25 进入未知状态 X。

1. 起初 X 为 `[-1, 1]`，根区间是 `[0.75 + 0.25×(-1), 0.75 + 0.25×1] = [0.5, 1]`，宽度 0.5，不能称为完成。
2. 搜索 X 后证明其区间为 `[0.2, 0.6]`，根收窄至 `[0.8, 0.9]`，宽度 0.1，仍未达到 0.02。
3. 再证明 X 在 `[0.4, 0.46]`，根变为 `[0.85, 0.865]`，宽度 0.015。此时已经足够，返回中点 0.8575，其效用误差至多 0.0075；没有必要把 X 求成精确值。

多行动时不能把所有格子直接平均，而要分别求上下界矩阵的博弈值：对手会选择回应，不是均匀随机选格。若效用为胜 +1／负 -1／平 0，`(V+1)/2` 是“胜利加半个平局”的分数；除非已知无平局，不能叫纯胜率。

## 如何选择下一步：优先影响当前证明的未知项

当前采用两类前沿选择，均只调度工作，不改变区间有效性：

- `security` 交替改善下界证明与上界证明。前者看最有希望提供最低保证的行，后者看最有希望限制对手上限的列，再处理其中较宽的单元；需要混合策略时会转用联合选择。
- `joint` 按“上界解的 P1 概率 × 下界解的 P2 概率 × 单元宽度”选择行动组合，然后按“转移概率 × 子状态宽度”沿后继继续。这里的两个策略来自不同界，不是已证明的真实联合均衡分布。零分数或退化情形还有宽度回退。

例如两个待求后继的概率／宽度分别是 `0.8 / 0.1` 与 `0.2 / 1`，对当前单元的不确定性贡献是 0.08 与 0.2。仅按发生概率会先选前者，按贡献则优先后者。这个分数不是未来耗时收益的精确预测，不保证全局最少展开。

默认 `auto` 从 security 开始；根矩阵的混合价值超出纯策略安全界时，转为 joint 并在该次求解中保持。判断不读取 fixture 或招式名称。

## 增量传播：信息没变，就不重算矩阵

共享后继用同一个节点表示，并记录其父节点。后继收窄时沿依赖关系更新，而不是遍历整个搜索树。若所有单元端点都未变，复用已有上下界矩阵解；如果精确性标记改变，即使数值端点未变也仍更新和传播。

例如 X 被多个行动到达，一次对 X 的证明可同时改善多个父状态；反之，某节点内部矩阵变动但对外区间与精确性不变时，父节点并没有得到新信息，无需继续向祖先重复传播。

## 当前配置、边界与证据

API 默认 `lazyCells: true`，允许逐格生成转移；benchmark 使用 `lazyCells: false`，展开选中节点时生成其一层行动组合。已提供惰性能力不代表它在 case 6 上更快；历史实验不支持这个结论。异步版只并行当前一层转移，未采用跨前沿流水。

预算检查发生在转移与 backup 之间，并在原生转移的随机分支边界协作截止；当前正在执行的模拟器调用不能被抢占，因此实际时间可能超预算。精确性与数值误差保护仍使用双精度实现，不是任意规则下的形式化证明。概率、矩阵与依赖图方法不要求固定行动数，但更大的行动生成和真正循环求解仍是独立问题。
